# My Custom Mouse Gestures

Google ChromeおよびBraveブラウザに対応した、軽量で安全な自分専用のマウスジェスチャー拡張機能です。

## 🚀 対応コマンド一覧

| ジェスチャー (右ドラッグ) | アクション |
| :--- | :--- |
| **← (L)** | 前のページに戻る |
| **→ (R)** | 次のページに進む |
| **↑ (U)** | ページ最上部へスクロール |
| **↓ (D)** | ページ最下部へスクロール |
| **↓→ (DR)** | 現在のタブを閉じる |
| **↓↑ (DU)** | ページのリロード (更新) |
| **↑→ (UR)** | 新しいタブを開く |
| **↑← (UL)** | 最後に閉じたタブを復元 |

## 🛠️ インストール手順

1. このリポジトリを `git clone` または ZIPでダウンロードします。
2. ChromeまたはBraveで拡張機能ページ（`chrome://extensions/` または `brave://extensions/`）を開きます。
3. 画面右上の **「デベロッパー モード」** をオンにします。
4. **「パッケージ化されていない拡張機能を読み込む」** をクリックし、本フォルダを選択します。
